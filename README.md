# Customer-Behavior-Analysis-Dashboard
Customer Behavior & Sales Analysis Dashboard
An interactive Power BI dashboard to explore customer behavior, sales, revenue, and subscription trends.
Features
- Analyze sales and revenue across product categories.
- Compare customer trends across age groups.
- Explore subscription patterns using filters for gender, category, shipping type, and subscription status.
1. Open the .pbix file in Power BI Desktop.
2. Connect the source dataset if required and refresh the report.
3. Use slicers to explore the dashboard.
